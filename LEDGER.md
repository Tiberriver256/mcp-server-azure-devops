## Full Prioritized Roadmap

### 1. Platform Modernization Track (Milestone M1: M1a / M1b / M1c)

- **Node 24/26 LTS & CI:** Upgrade PR CI (`.github/workflows/main.yml`) from Node `22` to a parallel Node `24` (Maintenance LTS) + Node `26` (Active LTS) `test` matrix plus a serialized `integration` job (`ado-integration-tests`); set `package.json` `engines.node` to `>=24.0.0` (targeting `0.2.0` via `feat!:` with local commits only); upgrade local VM Node via `/opt/nvm`; clean `dist/` before `tsc` in `npm run build`; align `README.md`, `CONTRIBUTING.md`, `.github/copilot-instructions.md` in M1c.
- **`tsconfig.json` `ES2024` & Erasable Native TS:** Bump `target` `ES2022` → `ES2024` while preserving CJS `dist/` output (no `"type": "module"`); convert the 2 `enum`s (`AuthenticationMethod`, `WikiType`) to `as const` + types; enable `erasableSyntaxOnly: true`; eliminate all 34 `@/` aliases; resolve relative and CJS subpath imports cleanly via Path A for zero-dep native Node 24/26 `.ts` execution.
- **Inspector Upgrade:** Update `package.json` `inspector` script from `@modelcontextprotocol/inspector@0.9.0` → `@modelcontextprotocol/inspector@2.16.0 -- node dist/index.js`.
- **Test-Runner 断捨離 (`node:test` + V8 Coverage):** Replace `jest`, `ts-jest`, `@types/jest`, legacy TS 6 alias (`"typescript": "npm:@typescript/typescript6@^6.0.2"`), and `tsx` with Node's built-in `node:test` + `node:assert/strict` + native V8 coverage (`lines >= 70%`, `branches >= 50%`, `functions >= 60%`) + `node --watch`; migrate all 71 offline + 39 int + 1 e2e suites + `tests/setup.ts`; remove `jest.*.config.js`, `tsconfig.jest.json`, and `jest: true` in `oxlint.config.mts`; achieve **pure TypeScript `7.0.2`** and **0 `npm audit` vulnerabilities** (eliminating all 18 moderate Jest advisories).

### 2. Tier 1 — High-Leverage Quick Wins (Milestone M2)

- **1.1 Prompt-Injection Spotlighting + Full MCP `ToolAnnotations`:**
  - Emit full `ToolAnnotations` (`title`, `readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`) for all tools via compile-time discriminated union in `src/shared/registry/tool-registry.ts`; safely classify `get_work_item_attachment` (writes local disk).
  - Zero-dep Microsoft delimiting Spotlighting (`src/shared/security/spotlighting.ts`: 128-bit CSPRNG hex nonce + private `Symbol` double-wrap guard + sanitized source label), applied centrally at the `CallTool` seam in `src/server.ts`, **ON by default** (confirmed policy) with `--no-spotlighting` / `AZURE_DEVOPS_SPOTLIGHTING=false` opt-out; raw `resources/read` code files left unwrapped.
- **1.2 Release `0.1.57` / `0.2.0` + Repo Hygiene:**
  - Release Please path targeting `0.2.0` via `feat!:` for `engines.node >=24.0.0`, keeping code commits local without pushing/publishing to GitHub/npm (confirmed policy).
  - Delete the **19 verified stale remote branches** on GitHub during M2 (confirmed policy), strictly preserving `main` and `pr-assets/maintenance-overhaul` (PR #423 chart assets), and record deletions in this ledger.

### 3. Tier 2 — Highest-Value Cross-Platform Feature Gaps (Cloud Services + On-Prem Server, Milestone M3)

- **2.1 Work Item Comments, Revisions & Teams:** `add_work_item_comment` (with auto project resolution, `>=7.1-preview.4` `?format=markdown`, and Server 2019 RTM `5.0` `PATCH System.History` fallback), `get_work_item_revisions` (bounded `$top` default `50`/max `200`), `list_teams` (project-scoped GA + org/collection-scoped preview, omitting `$expandIdentity` when unset/Server 2019).
- **2.2 PR Review Actions & Branches:** Shared cross-platform identity resolution (`connection.connect()` `/_apis/connectionData` + `identityBaseUrl` `vssps` on Cloud vs `coreBaseUrl` on Server); `vote_pull_request` (auto-deriving `repositoryId` & self `reviewerId`, preserving `isRequired`); `manage_pull_request_reviewers` (list/add/update `isRequired`/remove with GUID/identity lookup & structured per-reviewer results); `list_branches` (via `vsoClient.getVersioningData` preserving `$top` + `x-ms-continuationtoken`, guarding `filter` vs `includeMyBranches`, optional `includeStats`).
- **2.3 CI Debugging Superpowers:** `get_build_test_results` (cross-platform `TestApi` `buildUri` → `Runs/{runId}/results`, GA `5.0`–`7.1`, `withResolvedRun`, `$top` 200/1000 cap, failure-focused defaults + run summaries) and `retry_pipeline_stage` (`buildApi.updateStage`, `204 No Content`, `withResolvedRun`, clear Server 2019 unsupported guidance).
- **2.4 Sprints / Iterations (`work` Toolset):** New read-only `work` toolset (aliases: `work`, `sprints`, `iterations`, `boards`) with 4 tools: `list_iterations`, `list_team_iterations` (client-side `past`/`future` filtering), `get_team_settings` (+ optional area paths), `get_iteration_work_items` (UUID validation + optional hydrated details).

### 4. Tier 3 — Strategic / Architectural Bets (Milestones M2, M5, M6)

- **3.1 Streamable HTTP Transport + Official Docker Image (M5):** Zero-dep `node:http` + SDK `StreamableHTTPServerTransport` (`/mcp`, `/healthz`, `/readyz`), stateful & stateless modes, port-agnostic `Host` + `Origin` DNS-rebinding guard (`403` pre-body), fail-closed non-loopback auth, opt-in per-request isolated PAT, HTTP filesystem-tool lockout, bounded `BoundedEventStore`, session cap + idle reaper, graceful `SIGTERM`/`SIGINT` drain, `res.on('close')` hook; multi-stage non-root `Dockerfile` (`node:24-slim` / `node:26-slim`) + `.dockerignore` + `HEALTHCHECK`.
- **3.2 On-Prem `api-version` Compatibility Matrix Tests (M6):** Checked-in JSON server profiles (`server-2019-rtm`, `server-2020`, `server-2022`, `services-cloud`), in-process contract simulator (`createMockAdoServer`), parameterized `node:test` compatibility matrix suite, per-area direct-HTTP version resolution fixes (`pipelines`, `search`, `wikis`, `analytics`), and updated `docs/important-knowledge/azure-devops-rest-api-research.md`.
- **3.3 Atomic Tools + `--toolsets` Presets & Token Trim (M2):** Retain atomic tools (no parallel consolidated mode), condense `create_commit`'s duplicated 5 KB description (~900 tokens saved), and add 4 curated workflow presets (`pr-review`, `ci-debug`, `boards`, `core`) in `src/shared/config/tool-filter.ts`.

### 5. OData Analytics Goldmine (Milestone M4)

- Add `analyticsBaseUrl` (`https://analytics.dev.azure.com/{org}` on Services, `coreBaseUrl` on Server) in `src/shared/azure-devops-url.ts` + shared `isSameOrigin` guard in `src/shared/http/http-client.ts`.
- New 100% read-only `analytics` toolset (`analytics`, `odata`):
  - `get_analytics_schema` (zero-dep `$metadata` EDMX parser listing entity sets, properties, custom `Custom_*` fields, and navigation properties).
  - `query_analytics` (Poka-yoke guarded OData v4 engine enforcing all 7 Microsoft `[BLOCKED]` rules, 3,000-char GET / single-op `$batch` guard, `DateTimeOffset` timezone check, same-origin `@odata.nextLink`, `$top` cap, `404`/`403` Analytics-disabled guidance).
  - `get_analytics_metrics` (curated `$apply` DORA/CI/Boards presets: `pipeline_pass_rate`, `pipeline_duration_percentiles`, `flaky_tests`, `failed_tests`, `work_item_cycle_time`, `work_item_counts`).

### 6. MCP Events New Primitive (Milestone M5)

- Core zero-dep `EventEngine` (`src/shared/events/`): bounded ring buffer (`v1:<epoch>:<seq>`, `truncated: true` on eviction), 5 canonical minimal-payload ADO events (`ado.pull_request.updated`, `ado.pull_request.checks_changed`, `ado.pipeline.run_state_changed`, `ado.work_item.updated`, `ado.git.pushed`).
- Dual opt-in ingestion: bounded Polling Watcher (Cloud + On-Prem, stdio + HTTP, auto idle teardown) + opt-in fail-closed `POST /webhooks/ado` ADO Service Hooks receiver (Basic Auth / secret header / optional HMAC-SHA256, `256 KiB` cap, constant-time compare).
- Three ultra-thin protocol adapters:
  1. **SEP-3415 (`io.modelcontextprotocol/events` Beta)** — `events/list`, `events/poll`, `events/stream` (`delivery: ["poll", "push"]`; error codes `-32023`..`-32027`; `events/subscribe` → `-32026` Unsupported).
  2. **`2025-11-25` Resource Subscriptions** — `resources/subscribe`, `resources/unsubscribe`, `notifications/resources/updated` on `ado://{org}/{project}/events/...`.
  3. **Opt-in `events` read-only toolset** — `list_event_types`, `poll_events` (Spotlighting applied).

### 7. Explicit Non-Goals (引き算の設計 — Strictly Enforced)

- **NO** interactive MSAL browser OAuth or `keytar` native bindings.
- **NO** Advanced Security (`advsec_*`) tools.
- **NO** parallel consolidated / action-dispatched tool mode (keep atomic tools + `--toolsets` presets).
- **NO** new runtime dependencies in `package.json` (strictly 5 runtime deps).
- **NO** deletion of `pr-assets/maintenance-overhaul` branch (hosts PR #423 chart PNGs).
